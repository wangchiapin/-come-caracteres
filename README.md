# 吃字小籠包 · Come Caracteres

在隨機迷宮裡吃掉冒出來的正確漢字，躲開亂跑的怪物（Pac-Man 玩法），給西語學習者練習詞語。
Juego estilo Pac-Man: come el carácter correcto y esquiva a los monstruos.

🎮 **開始玩 / Jugar:** https://wangchiapin.github.io/-come-caracteres/
（repo 名稱開頭有一條橫線 `-come-caracteres`，網址也是。）

給 Claude：改這個遊戲前先讀這份，再讀 game-kit 的 README。Ben 的規則：先討論、測好、問過才推（他說「推」才推）；用白話繁體中文說明。

## 玩法

- 地圖是 15×19 的隨機迷宮，每一局和每次升級都重新產生；左右兩邊在第 9 列有隧道可穿過。
- 題目給提示，玩家吃掉正確的詞：
  - **文字模式**：看西文或英文提示，找對應的漢字。
  - **聽力模式 🔊**：聽聲音找漢字。介面選「純中文」時只能用聽力模式。
- **吃錯字扣 50 分，不扣命**。怪物碰到你會少一顆 ♥（共 3 顆）。沒有難度選擇。
- 玩家是小籠包；怪物有機車、蚊子、野狗、颱風。
- **珍珠奶茶**：每答對 3 題會出現一杯（只留約 14 秒，快消失時會閃）。喝到之後 8 秒內怪物變慢（速度 ×0.6），而且可以反過來吃怪物，吃到 +50 分。
- **彩蛋**：主頁連點小籠包 5 下，小籠包會跳起來、噴蒸氣、說一句台灣常用語；連續答對每滿 10 題會有「滿籠」特效（只有特效，不加分）。
- 有背景音樂，畫面角落有 🔊 一鍵靜音（只關音樂和音效，不關念中文）。

## 字庫

- 內建「墨龍飛天」的 630 詞字庫（10 個主題），寫在 `index.html` 的 `BANK:START ～ BANK:END` 之間，玩的時候不讀 Firebase。
- 字庫要和墨龍同步時，不要手改，用工具：
  ```
  node tools/sync-bank.js /路徑/el-dragon-de-tinta/index.html
  ```
  它會把墨龍的 `THEMES` 轉成本遊戲的字庫（含注音），只改動那兩個標記之間的內容。注音轉換已處理：`ng` 後面接母音時 g 歸下一個音節（例如 dàngāo → dàn＋gāo）、`er` 轉ㄦ。
- 詞語讀音依 GoodTeacher 規則（例如「頭」念 2 聲、「髮」念 3 聲），跟墨龍一起維護。

## 排行榜與暱稱

- 主頁要先輸入**暱稱**，沒填不能開始（會提示並把游標移到輸入框）。
- 結束時**自動上傳**排行榜（不用另外按鈕、也沒有輸入框）；只有上傳失敗才會出現「重新上傳」。
- 排行榜在 Firebase 專案 `memorma-24dab` 的 `comeCaracteresLeaderboard`，顯示前 10 名（快取 60 秒）；不比舊的高時，分數維持不變、只更新暱稱。
- 瀏覽器不讓存資料（例如無痕模式）時，這一局仍會記得暱稱。

## 設定與遊玩紀錄

- 共用設定 `hanziGames.settings`：字形（繁／簡）、語言（西／英／純中文）、拼音／注音、語速三段。
- 遊玩紀錄代號 `come_caracteres`，寫到 `memorma-24dab` 的 `plays`、`visits`。
- 語音只選台灣中文，找不到時會提示。
